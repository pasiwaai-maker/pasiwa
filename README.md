# 星星考題樂園（Visual Studio 專案）v3.4

國小 1–6 年級、國中 7–9 年級各科互動段考模擬卷的 Windows 桌面程式。首頁分「國小」「國中」兩個頁籤；國小科目為國語、數學、英語、自然、社會（1–2 年級為生活）與「何嘉仁美語」；國中科目為國文、英文、數學、自然、地理、歷史、公民與「大家說英語」（不分版本，分基礎／進階／挑戰三個階段）。程式用 C# WinForms 搭配 Microsoft Edge WebView2 顯示互動介面，可以作答、自動評分、訂正詳解，也有錯題本。學生每次進入考試，都從題庫隨機抽題，並優先抽最近沒做過的題目。右上角的「家長模式」（預設密碼 0000）可以設定每次 10／20／30 題、查看學習紀錄、更新題庫和變更密碼。作答中可按「清除作答，重新開始」回到還沒作答的狀態；首頁的「恢復未作答」可清除某一科或全部的成績、星星與錯題本。

## 開發環境需求

- Visual Studio 2022（17.8 以上），安裝時勾選「.NET 桌面開發」工作負載
- .NET 8 SDK（隨 Visual Studio 安裝）
- Microsoft Edge WebView2 Runtime（Windows 10/11 通常已內建）
- Windows 10（1809 以上）或 Windows 11；考卷 OCR 需要安裝「中文（繁體）」光學字元辨識（見下方）
- 第一次建置需要連網，NuGet 會自動下載 `Microsoft.Web.WebView2` 套件

## 開啟與執行

1. 解壓縮後，雙擊 `StarExam.sln` 用 Visual Studio 開啟。
2. 按 **F5** 執行（偵錯模式下可按 F12 開啟網頁開發者工具）。
3. 程式內按 **F11** 可切換全螢幕，**Esc** 離開全螢幕。

## 發佈給學生使用

1. 在「方案總管」對 **StarExam** 專案按右鍵，選「發佈」。
2. 選擇已附的設定檔 **FolderProfile**，再按「發佈」。
3. 輸出位置：`StarExam\bin\publish\StarExam\`。把整個資料夾複製到學生電腦，執行 `StarExam.exe` 就能使用，不用另外安裝 .NET。

也可以用命令列：

```
dotnet publish StarExam\StarExam.csproj -p:PublishProfile=FolderProfile
```

注意：`wwwroot` 資料夾必須和 `StarExam.exe` 放在一起。

## 成績存在哪裡

學生的最佳成績、星星、錯題本、學習紀錄和家長設定存在 `%LOCALAPPDATA%\StarExam`，每台電腦、每個 Windows 帳號各自一份。刪除這個資料夾就能清除紀錄。

## 新增或修改題目

用任何文字編輯器打開 `wwwroot\data\questions.js`。每題是一行 JSON 物件，放在 `window.QUESTION_BANK = [ ... ];` 裡面，題目之間用逗號分隔。修改後重新執行程式就會生效；已發佈的版本可以直接改 `bin\publish\StarExam\wwwroot\data\questions.js`，不用重新編譯。

| 欄位 | 說明 | 範例 |
|---|---|---|
| `id` | 唯一代碼 | `"mat-g3-e1-01"` |
| `s` | 科目：`chinese` 國語（國中顯示為國文）、`math` 數學、`english` 英語、`life` 生活、`nature` 自然、`society` 社會（國小）、`geo` 地理、`his` 歷史、`civ` 公民（國中）、`hess` 何嘉仁美語（1–6 年級）、`ltie` 大家說英語（7–9 年級） | `"math"` |
| `g` | 年級 1–9（7–9 為國中） | `3` |
| `e` | 段考：國小 1–2、國中 1–3（何嘉仁美語、大家說英語為階段 1–3） | `1` |
| `v` | 版本題組（可省略）：`kang` 康軒、`nan` 南一、`han` 翰林；省略表示所有版本共用 | `"nan"` |
| `unit` | 單元名稱 | `"四位數加減"` |
| `type` | `mc` 選擇、`tf` 是非、`fill` 填充 | `"mc"` |
| `q` | 題目 | `"7000－2846＝？"` |
| `img` | 題目附圖（可省略）：`data:image/jpeg;base64,…`、`img/檔名.png` 或 https 網址 | |
| `opts` | 選擇題的 4 個選項（只有 `mc` 需要） | `["4154","4254","5846","4164"]` |
| `optImgs` | 選項是圖片時的 4 張圖（可省略），此時 `opts` 填 `["(A)","(B)","(C)","(D)"]` | |
| `ans` | 選擇題填正確選項的位置（從 0 起算）；是非題填 `true` 或 `false`；填充題填一個陣列，列出所有可接受的寫法 | `0`、`true`、`["12","12公分"]` |
| `exp` | 詳解 | `"7000－2846＝4154"` |
| `trap` | 答錯時顯示的「錯在哪裡」 | `"退位時忘記減 1"` |

規則：

- 國小學校科目只有第 1、2 次段考（舊資料的第 3 次段考會自動併入第 2 次）；國中有第 1、2、3 次段考。
- 學生選某個版本時，會從「共用題＋該版本題」中抽題。第 1 次段考只抽段考 1 的題目；之後的段考約八成抽本次範圍、兩成抽前面範圍。
- 「全冊總複習」把前面每一次段考的題目都納入，題數平均分配到各次段考（某次題庫不夠時由其他次補足）。
- 題庫不夠家長設定的題數時，會以實際題數出題，並平均分配 100 分。
- 選擇題的選項順序每次都會隨機打亂，`ans` 填原始順序的位置即可。選項含「以上」或「皆」時不會打亂。
- 填充題比對答案時會忽略空白、全形半形差異和英文大小寫；數字答案多寫或少寫單位也算對。

## 雲端題庫

家長模式第 3 區的雲端網址可以修改，預設是 `https://drive.usercontent.google.com/open?id=1HoZvyqXeJ9qKc89oleXjkUWcrv4_pJi0`（也接受 `drive.google.com/file/d/…` 分享連結）。

- **讀取（下載並更新、每天自動同步）**：雲端檔案共用設為「知道連結的任何人」可檢視時不需要登入；已連結 Google 帳號時，程式自己建立的雲端檔案也能直接下載。下載後依原本格式併入 `wwwroot\data\questions.js`（舊檔先備份）；勾選「以雲端檔案為準」時改成完全同步。
- **寫入雲端**：匯入考卷只更新本機題庫。要把本機題目放到雲端，可在第 5 區連結 Google 帳號後按「本機新題目上傳雲端（只新增）」，或自行把 `questions.js` 上傳成雲端檔案的新版本。
- **還原成內建題庫**：用第一次更新時保留的 `questions.original.js` 還原。

### 第 5 區：連結 Google 帳號與辨識設定

第 5 區需要先輸入管理者密碼才會顯示（程式只保存密碼的 SHA-256 雜湊值，不保存密碼本身）。

1. 輸入 Gmail，按「連結 Google 雲端硬碟」，在 Google 的「選擇帳戶」畫面選正確帳號、輸入密碼並按「允許」。密碼只交給 Google，程式只保存授權權杖（Windows DPAPI 加密）。權限範圍 `drive.file`：程式只能存取自己建立的 Questions.js 與備份檔。
2. 「進階設定」可填 Anthropic API 金鑰（考卷辨識用）與自訂 Google 用戶端（用戶端 ID 格式是 `數字-英數.apps.googleusercontent.com`，密鑰以 `GOCSPX-` 開頭；不要填 Gmail）。
3. 開發者一次性設定：Google Cloud Console 建專案 → 啟用 Google Drive API →「OAuth 同意畫面」（外部、加入範圍 `.../auth/drive.file`、發佈狀態「正式版」）→ 建立「桌面應用程式」OAuth 用戶端 → 填進 `google_oauth.json` 後重新建置。
4. 連結後可按「在雲端建立 Questions.js」，由程式在雲端建立並管理題庫檔。

### （選用）Apps Script 雲端寫入服務

不想設定 Google Cloud 時的替代做法：把 `AppsScript\StarExam_雲端題庫.gs` 貼到 <https://script.google.com/>，加入 Drive API 服務、（要辨識時）在指令碼屬性加 `ANTHROPIC_KEY`，部署為網頁應用程式（執行身分「我」、存取權「所有人」），把網址填進 `cloud_config.json` 的 `scriptUrl`。

## 家長模式：匯入考卷 PDF／JPG（線上免費 AI 判讀）

v3.0 起，考卷改由線上免費 AI 判讀：每頁轉成圖片，連同 PDF 內嵌文字一起送給 AI，一次完成題目、選項、答案、附圖與詳解。結果只新增到本機 `wwwroot\data\questions.js`。

**第一次使用：申請免費金鑰（管理者做一次）**

1. 用瀏覽器開 https://aistudio.google.com ，以 Google 帳號登入（第一次會要求同意使用條款）。
2. 左側「Get API key」→「Create API key」，複製「AIza」開頭的金鑰。免費方案不需要信用卡，每分鐘、每天有使用上限。
3. 程式家長模式第 5 區輸入管理者密碼 →「線上 AI 金鑰」選「Google Gemini」→ 貼上 →「儲存」，會自動測試連線。
4. （選用）也可以到 https://openrouter.ai →「Keys」申請 OpenRouter 金鑰當備援。設定多個時，一個額度用完會自動換下一個（Gemini → OpenRouter → Ollama 雲端）。
5. 金鑰只存在 Windows 加密儲存，介面不會顯示；也可以填在 `ai_config.json` 的 `geminiApiKey`／`openrouterApiKey`，程式第一次執行時會搬進加密儲存並清空檔案。

注意：原本的 Ollama 雲端金鑰測試時回應「402 帳號沒有可用額度」，Ollama 雲端目前需要付費額度，因此改以 Gemini 為主。

**匯入步驟**

1. 第 4 區選年級、科目、段考（檔名裡有「七年級」「數學」「第一次」等字會自動帶入）、版本、出處。
2. 按「選擇考卷 PDF／JPG」，可同時選題目卷和答案卷。檔名含「答案」「解答」「詳解」的檔案會當成答案卷。
3. 程式自動處理（每 2 頁一批，每批約 20–60 秒；免費額度到達每分鐘上限時會自動等候再繼續）：
   - AI 逐題抄錄題目與 4 個選項（不含題號、作答括號、選項代號），題組的共用文章放進每一小題開頭。
   - 讀答案卷對答案；沒有答案卷時由 AI 自行解題，並以黃色標示「請確認」。
   - AI 標出題目附圖（圖、表、地圖、統計圖、幾何圖形、照片）的位置，程式自動從原稿裁切附上；選項是圖片時也會裁成選項圖。
   - 同時產生詳解與「錯在哪裡」。
4. 預覽清單每一題都可以修改。附圖框得不準時按「更換附圖」重新框選，不需要的按「移除附圖」。
5. 「AI 重新產生詳解（線上）」可整批重寫詳解（有附圖的題目會連圖一起送給 AI）。
6. 按「加入本機題庫（只新增）」：只把新題目加到 `wwwroot\data\questions.js`，寫入前先把原檔備份成 `questions.backup-日期時間.js`。

沒有設定任何線上金鑰、或網路不通時，會自動改用 v2.6 的本機解析（PDF 文字層＋Windows 內建 OCR＋規則切題），「AI 重新產生詳解」改用免費本機 AI（Ollama，第一次會自動下載安裝）。

Google AI Studio 免費方案的內容可能被 Google 用來改善服務，請只上傳學校段考卷等可公開的內容，不要上傳含學生個資的檔案。

**安裝中文 OCR（掃描檔需要，只做一次）**：Windows「設定 → 時間與語言 → 語言與地區 → 新增語言 → 中文（台灣）」，選用功能勾選「光學字元辨識」；或以系統管理員身分在 PowerShell 執行：
```
Add-WindowsCapability -Online -Name "Language.OCR~~~zh-TW~0.0.1.0"
```

自動切題無法處理所有排版（例如雙欄、題號寫在圖裡），請在預覽中檢查。學校段考試題依著作權法第 9 條一般不受保護；出版社或補習班教材請只匯入你有權使用的內容。

## AI 服務設定（ai_config.json）

`StarExam\ai_config.json` 可設定：

| 欄位 | 用途 |
|---|---|
| `geminiApiKey` | Google Gemini 金鑰（第一次執行後移入加密儲存並清空） |
| `openrouterApiKey` | OpenRouter 金鑰（同上） |
| `apiKey` | Ollama 雲端金鑰（同上） |
| `geminiModels` | 依序嘗試的 Gemini 模型，預設 `gemini-flash-latest` 等；某個模型下架時自動換下一個 |
| `openrouterModels` | 依序嘗試的 OpenRouter 免費模型（`:free` 結尾或 `openrouter/free`） |
| `ollamaModels` | 依序嘗試的 Ollama 雲端模型 |

模型名稱若日後改名，直接修改這幾個清單即可，不用重新編譯。專案原始碼和建置出來、還沒執行過的資料夾裡可能含有金鑰，請不要公開分享。
